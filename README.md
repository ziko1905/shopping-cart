<h1 align="center"> React Shopping Cart </h1>

<p align="center">
  Frontend of a generic Shopping Cart page built with React. This website includes API fetching for generic products and then displays them in a comprehensive manner.
  Each product can be added to the shopping cart from where a checkout can be processed. After the checkout, there is a  descriptive message to indicate if everything went right.
</p>
